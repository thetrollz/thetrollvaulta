# **App Name**: The Troll Vault

## Core Features:

- Password Storage: Securely store user passwords using advanced encryption techniques.
- Password Generation: Generate strong, random passwords based on user-defined criteria.
- Automatic Login: Automatically fill in usernames and passwords on websites.
- Data Breach Monitoring: Monitors the Dark Web to check if any of the users passwords are in a list of breached passwords.
- Key File Authentication: Supports authentication using key files instead of 2FA codes.
- Secure Notes: Store sensitive notes, such as credit card information or social security numbers, in a secure, encrypted vault.

## Style Guidelines:

- Primary color: Black (#000000) to represent security.
- Background color: Green (#00FF00) to ensure readability and a modern look.
- Accent color: Black (#000000) for highlighting important elements.
- Headline font: 'Space Grotesk', a sans-serif font, to communicate a computerized, techy feel; suitable for headlines and short amounts of body text; longer text to use 'Inter' for body.
- Code Font: 'Source Code Pro' for any code snippets to enhance readability.
- Crisp, modern icons representing password management functions and security features.
- Subtle transitions and loading animations to enhance user experience.
